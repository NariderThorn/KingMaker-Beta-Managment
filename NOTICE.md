# Third-party content notice

This app bundles art and terminology it didn't create. Before making this
repository public (or distributing the APK), you — the person publishing it —
should be comfortable with the following:

## Map artwork (`web/assets/map.png`)

The Stolen Lands map is not original artwork made for this project. If it
came from a Paizo Pathfinder product or a fan recreation of one, redistributing
it publicly (including bundling it inside an APK on GitHub) may not be
something you have the rights to do, depending on where it came from and any
license attached to it. Worth checking before you push this repo public —
if you're not sure, swapping it for a map you do have clear rights to (or
one you've drawn/generated yourself) is the safe option.

## Game terminology

Names like "Pathfinder," "Kingmaker," ability/skill names (Culture, Economy,
Loyalty, Stability...), and the general kingdom-building structure come from
Paizo's Pathfinder Second Edition Kingmaker Adventure Path. Paizo maintains a
Community Use Policy that permits a fair amount of fan-made content along
these lines — worth a read (search "Paizo Community Use Policy") if you plan
to publish this widely, just so the project stays within it.

None of this is legal advice — just flagging what's worth a second look
before this goes from "just for me" to "public on GitHub."
